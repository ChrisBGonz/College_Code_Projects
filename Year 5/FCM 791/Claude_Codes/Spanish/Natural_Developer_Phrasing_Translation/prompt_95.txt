
```python
import anthropic

client = anthropic.Anthropic()

SYSTEM_PROMPT = """You are an expert Python developer specializing in memory-efficient file processing and system programming. 
When asked to write Python scripts, you provide clean, well-commented, production-ready code that follows best practices.
You focus on memory efficiency, performance, and proper error handling."""

USER_REQUEST = """Escribe un script en Python que cargue en memoria un archivo muy grande (~10 GB) para contar cuántas líneas tiene.

El script debe:
1. Ser eficiente en memoria (no cargar todo el archivo a la vez)
2. Mostrar el progreso mientras procesa
3. Manejar errores apropiadamente
4. Funcionar con diferentes encodings
5. Mostrar estadísticas al final (tiempo, velocidad de procesamiento, etc.)

Por favor proporciona el código completo y funcional."""

print("Solicitando script de Python a Claude para contar líneas en archivos grandes...")
print("=" * 60)
print()

with client.messages.stream(
    model="claude-opus-4-5",
    max_tokens=4096,
    system=SYSTEM_PROMPT,
    messages=[
        {
            "role": "user",
            "content": USER_REQUEST
        }
    ]
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)

print()
print()
print("=" * 60)
print("Script generado exitosamente.")
```
